# 🚀 Gegeminini

A modern desktop application built with **Tauri** and **React**. This project leverages **Rust** for its backend core and **Sled** as an embedded high-performance key-value database for data persistence.

---

## 🛠 Tech Stack

### Backend (Core)

- **Rust**: High-performance, memory-safe systems programming language.
- **Tauri**: Framework for building cross-platform desktop apps with smaller footprints and better security.
- **Sled**: A high-performance embedded database (KV store) for local data persistence.
- **Bincode & Serde**: Efficient binary serialization for Rust data structures.

### Frontend (UI)

- **React (TypeScript)**: For building a responsive and type-safe user interface.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **daisyUI**: The most popular component library for Tailwind CSS, providing clean and customizable themes.
- **Vite**: Next-generation frontend tooling for fast development.

## 📌 Git Commit Guidelines

To maintain a clean and readable project history, please follow these commit message prefixes:

| Prefix       | Description                                                                                |
| :----------- | :----------------------------------------------------------------------------------------- |
| **feat**     | A new feature                                                                              |
| **fix**      | A bug fix                                                                                  |
| **docs**     | Documentation only changes                                                                 |
| **style**    | Changes that do not affect the meaning of the code (formatting, missing semi-colons, etc.) |
| **refactor** | A code change that neither fixes a bug nor adds a feature                                  |
| **test**     | Adding missing tests or correcting existing tests                                          |
| **chore**    | Changes to the build process or auxiliary tools and libraries                              |

### Format

`<prefix>: <description>`
